Phasor Tutorial — Adding Waves with Arrows

1
A wave as an arrow. At a point in space, wave number `k` makes the oscillation `y_k = A_k sin(omega t + theta_k)`. We draw it as an arrow (a phasor) of length `A_k` (its amplitude) pointing at the angle `theta_k` (its phase), measured counterclockwise from the right, like any vector. As time goes on, all the arrows turn together at the same rate `omega`, so only the angles between them matter: we freeze them at `t = 0`.
2
The phase difference. In every example, each wave lags the previous one by the same angle `phi`. So arrow `k` is turned by `phi` from arrow `k - 1`, and it points at `theta_k = (k - 1) phi`. Angles past 360° just go around again (405° is the same as 45°).
3
Adding waves = adding vectors. The total oscillation is `y = y_1 + y_2 + ... + y_N`. It is again a wave, and its arrow is the resultant `vec R = vec A_1 + vec A_2 + ... + vec A_N`: put the arrows tip to tail, exactly as you add forces or displacements. In components:
`x_k = A_k cos theta_k`,   `y_k = A_k sin theta_k`,   `R_x = x_1 + x_2 + ... + x_N`,   `R_y = y_1 + y_2 + ... + y_N`.
4
The amplitude of the total wave is the length of the resultant: `|R| = sqrt(R_x^2 + R_y^2)`. You can measure it on the grid (one square = 0.5) or compute it from the components.
5
Brightness. The intensity of a wave is proportional to the square of its amplitude. The brightest possible is when all the arrows line up, `|R| = A_1 + A_2 + ... + A_N`, so `I/I_"max" = |R|^2/(A_1 + A_2 + ... + A_N)^2`. Example: 2 equal waves with `|R| = 1` give `I/I_"max" = (1/2)^2 = 25%`.
6
Where does `phi` come from? Light from two slits a distance `d` apart reaches a point on the screen at angle `theta`. One path is longer by `d sin theta`, so that wave lags by `phi = 360° (d sin theta)/lambda`. Moving along the screen changes `phi`, and so changes the brightness: that makes the fringes.

Help

When several waves of the same frequency arrive at a point, the wave you get there depends on how far each one is behind the others. A phasor is an arrow that represents one wave: its length is the wave’s amplitude, and its direction is the wave’s phase. Adding the waves is the same as adding the arrows tip to tail.

In each example, every wave is behind the previous one by the same phase difference `phi` (for light behind slits or a grating, `phi = (2 pi d sin theta)/lambda`). So each arrow is turned by `phi` from the one before: arrow `k` points at `(k - 1) phi`, measured counterclockwise. The resultant arrow goes from the tail of the first arrow to the tip of the last one; its length `|R|` is the amplitude of the combined wave, and the brightness is

`I/I_"max" = (|R|/(A_1 + A_2 + ... + A_N))^2`.

How to use it. Arrow 1 is given, pointing right. Aim each next arrow from the tip of the previous one (move the pointer, or use the ← → keys) and click (or press Enter) to place it. Then click where the resultant ends, measure its length on the grid (one square is half a wave), type `|R|` and press Check. The solution and the graph of brightness for every `phi` appear only after you check (or if you ask for the solution). Help options show the turn of each arrow, or, as a hint, the direction to aim for.

What to look for. When `phi` is a whole number of turns, all arrows line up: brightest (principal maximum). When the arrows close into a polygon (`N phi` a whole number of turns), they cancel: dark. With 3 or more waves, between the dark points the arrows curl around without quite closing, leaving a small resultant: the weak secondary maxima. With unequal amplitudes, the cancellation is never complete.
