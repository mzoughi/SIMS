The scales compared

In the ripple tank the sources, the wavelength and the distance to the interference pattern are all about the same size, so the whole pattern fits in one picture. For light they are not: the slits are a fraction of a millimetre apart, the wavelength is about a thousand times smaller still, and the screen is about a metre away. So this SIM shows the same light pattern in three panels, each with its own scale (given in its title), and a fourth panel that adds up the waves.

1. Near the slits (micrometres across). Because P is so far away, the rays to it are practically parallel, and the extra distance one ray travels is the highlighted path difference `Delta = d sin theta`. The true angle is tiny, so by default it is drawn larger (the factor is shown). 2. In between (not to scale): `L` is thousands of times larger than `d`, so it is broken. 3. The screen (millimetres across): bright fringes where `d sin theta = m lambda`, with `tan theta = x/L` and spacing `Delta x ~~ lambda L//d`.

Σ. Adding the waves: phasors and secondary maxima. Each slit sends a wave of the same size to P; each one is behind the previous one by the phase difference

`phi = (2 pi d sin theta)/lambda`.

Draw each wave as an arrow (a phasor), each turned by `phi` from the one before, and add them tip to tail. The length of the sum is the amplitude at P; the intensity is its square:

`I/I_0 = ((sin(N phi//2))/(N sin(phi//2)))^2`.

When `phi` is a whole number of turns, all `N` arrows line up: a principal maximum. When `N phi` is a whole number of turns (but `phi` is not), the arrows close into a polygon and cancel: a zero, at `phi = 2 pi k//N`. So between two principal maxima there are `N - 1` zeros, and between each pair of neighbouring zeros the arrows curl around without quite closing: a small leftover, a secondary maximum. There are `N - 2` of them, and they are weak (about 5% of a principal maximum for large `N`). With 2 slits there is one zero and no secondary maxima; as `N` grows, the principal maxima get narrower and the secondary maxima more numerous and smaller, as in a diffraction grating. The right graph shows one cycle, `phi` from 0 to `2 pi` (`Delta` from 0 to `lambda`); the dotted curve is the same graph magnified 5 times so the small bumps can be seen.

The single-slit envelope `(sin beta//beta)^2`, `beta = pi a sin theta//lambda`, multiplies this pattern when the slits have a finite width `a`. This is the Fraunhofer (far-field) model: it replaces the exact path difference `r_1 - r_2` by `d sin theta`, excellent when `L` is well beyond `D^2/lambda` (`D` the width of the slit array); the readout compares the two. (The ripple-tank SIM uses the exact distances, which is why its fringes curve near the sources.)
