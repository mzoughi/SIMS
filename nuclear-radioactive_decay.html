When a nucleus transforms into another with the emission of radiation, it decays. Decay is random: there is no way to tell when a particular nucleus will decay. But the number decaying in a time `dt` is proportional to the number `N` of parent (undecayed) nuclei present,

`dN = -lambda N dt`,

where `lambda` is the decay constant. The solution is the radioactive decay law,

`N = N_0 e^(-lambda t)`.

The half-life `T_(1/2)` is the time for half of the original nuclei to decay; after `n` half-lives, `N = N_0 (1/2)^n`. Setting `N = N_0/2` gives `T_(1/2) = (ln 2)/lambda = 0.693/lambda`. The lifetime `bar T = 1/lambda` is the average time a nucleus exists before decaying. The activity is the magnitude of the decay rate, `A = |dN/dt| = lambda N = A_0 e^(-lambda t)`, measured in becquerels (1 Bq = 1 decay/s) or curies (1 Ci = `3.70 xx 10^10` Bq). Since `ln A = -lambda t + ln A_0`, a plot of `ln A` against `t` is a straight line of slope `-lambda`.

Every decay turns a parent into a daughter, so the daughters grow as `N_D = N_0 - N = N_0(1 - e^(-lambda t))`, and the rate at which daughters appear, `dN_D/dt = lambda N`, is the activity. In the simulation each nucleus is drawn as a small cluster of protons and neutrons, placed at random; each decay is marked on the timeline at the moment it happens, and the number of decays in each half-life is compared with the expected `N_0/2, N_0/4, ...`. Because decay is random, small samples scatter widely around the law; large ones follow it closely. The real-sample panel repeats Example 12.4.3 for any mass.
