Color code reference
ColorDigitMultiplierTolerance

Digit and multiplier bands are read from left to right, starting with the band closest to one end. The tolerance band is usually gold or silver and sits by itself, separated slightly from the others — that gap tells you which end to start reading from.

A resistor’s value is printed as coloured bands. On a 4-band resistor, the first two bands are digits, the third is a multiplier (a power of ten), and the fourth is the tolerance; a 5-band resistor has three digit bands. Each colour stands for a digit: black 0, brown 1, red 2, orange 3, yellow 4, green 5, blue 6, violet 7, grey 8, white 9. Gold and silver multiply by 0.1 and 0.01.

For example, yellow, violet, red, gold reads 4, 7, ×100, ±5%: 4700 Ω = 4.7 kΩ, so the true resistance lies between 4.465 kΩ and 4.935 kΩ. The tolerance band usually stands slightly apart: that gap tells which end to start reading from.

Choose the colours of each band to read the value. With COLOR-BLIND SAFE on, every band is labelled with its colour name, on the resistor and on the choices, so the code can be read without telling the colours apart.
