Event types: topic (what is covered that day), due, quiz, exam, lab, note, cancel (cancels the regular meetings that day). Up to 6 courses; color, time, note, link and where are optional. Regular meetings repeat every week between the term dates, except on holidays.

GitHub version: add ?data=URL-of-your-json to the page address to load an external file automatically. Edits are kept in this browser only; use Download to save them.

A week-at-a-time calendar for up to six courses. Regular class meetings repeat automatically through the term, skipping holidays; dated items (topics, assignments due, quizzes, exams, labs, notes, cancellations) are added on their day.

Choose the courses to show with the coloured buttons: one course, several, or all. The Week view shows the days side by side; the Agenda list shows the same items as a list, easier to read with a screen reader or on a phone. Today is outlined.

The schedule is stored as JSON: built into the page, loaded from a file or a web address, or pasted in the Data tab. To share one course with its students, select only that course, copy the link in the Data tab, and post it; the locked link hides the other courses and the editor.
