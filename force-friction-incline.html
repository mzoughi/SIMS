Physics (with friction):
N = mg cosθ
f_k = μkN  (opposes motion)
a = g(sinθ − μkcosθ), if tanθ > μs
Stays put if tanθ ≤ μs
Tilt test: slips when tanθc = μs, so μs = tanθc

f_k does NOT depend on contact area!
μ values carry ±0.03 typical table uncertainty; each trial varies slightly, as in a real lab.
