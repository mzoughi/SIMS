Click any square to follow one nucleus: you can never tell when it will decay, only the chance that it will.

Radioactive decay is random: there is no way to tell when a particular nucleus will decay. Each one has the same chance to decay in each second, whatever its age (it does not “wear out”). But with many nuclei, the total behaves very predictably.

The half-life `T` is the time in which half of the nuclei of a sample decay, on average. What is left then halves again in the next half-life, and so on:

`N = N_0 (1/2)^(t/T)`    (equivalently `N = N_0 e^(-lambda t)`, `lambda = (ln 2)/T`)

The activity, the number of decays per second, is proportional to the number left, `A = lambda N`, so it halves every half-life too. Each square is one nucleus; the graph compares this sample (blue) with the expected curve (white). Because decay is random, real samples scatter around that curve by about `sqrt(N_0 p(1 - p))`, where `p = (1/2)^(t/T)`: large compared to small samples, tiny compared to large ones. “Repeat 50 times” measures the half-life on 50 fresh samples to show this spread. The isotope only changes the time unit: every isotope follows the same curve when time is counted in its own half-lives.
